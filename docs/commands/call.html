Call

The Call command transfers execution to another block. It is the primary way to link blocks together in a linear sequence.

Fields

FieldTypeDescription
Target Block Block reference The block to jump to. Select from a dropdown of all blocks in the project.

Behaviour

When a Call command executes, the runtime immediately begins executing the first command in the target block. A connecting line is drawn on the canvas from the calling block to the target block.

On the canvas, a Call creates a visible arrow between the two blocks:

#1 Introduction
→
#2 Chapter 1

Call is typically placed as the last command in a block to hand off to the next step in the flowchart.

Debugging Calls

In Debug Mode, Call commands support two stepping behaviours:

  • Step Into — Enter the target block and step through its commands one by one.
  • Step Over — Run the entire target block to completion and return to the next command after the Call.

Example

☰ Say "Welcome to the adventure!"
☰ Call → Chapter 1

After the player reads the welcome text, execution moves to Chapter 1.
