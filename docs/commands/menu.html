Menu

The Menu command presents the player with a set of clickable choices. Each choice has a label and a target block. When the player picks a choice, execution jumps to the corresponding block.

Fields

FieldTypeDescription
Choices List One or more choice entries, each with a label (the text shown to the player) and a target block (the block to jump to when selected).

Canvas Connections

Each choice creates a visible connection line on the flowchart canvas from the current block to the target block. This makes Menu commands easy to trace visually — the block will show multiple outgoing arrows, one per choice.

Example

Two consecutive Menu commands group together to present three choices:

☰ Say "You reach a fork in the road."
☰ Menu "Go left" → Forest Path
☰ Menu "Go right" → Mountain Trail

The player sees buttons for each Menu choice. Clicking "Go left" jumps execution to the Forest Path block, and so on. Consecutive Menu commands are grouped together and presented as a single set of choices at runtime.

Tip
A Menu command is typically the last command in a block, since execution leaves the block once the player makes a choice.
