Set Variable / Copy Variable

These commands modify variable values at runtime. Use them to track state, count items, toggle flags, and more.

Set Variable

Set Variable assigns a new value to an existing variable.

FieldDescription
Variable The variable to modify (selected from a dropdown).
Operation How to apply the value: Set (assign), Add, Subtract, Multiply, Divide. Arithmetic operations apply to Integer and Float types. Boolean variables support Set and Toggle.
Value The literal value to use with the operation.

Copy Variable

Copy Variable copies the current value of one variable into another. Both variables should be of the same type.

FieldDescription
Source The variable whose value is read.
Destination The variable whose value is overwritten.

Example

A command list using Set Variable and Copy Variable:

☰ Set Variable gold Add 5
☰ Set Variable hasKey Set true
☰ Copy Variable tempScore → finalScore
Tip
Variable changes are visible in real time during Debug Mode — modified variables are highlighted after each step.
