Stage BG Color / Stage BG Image

Stage commands change the visual appearance of the runtime stage background. Use them to set the mood, indicate scene changes, or provide visual context for your story.

Stage BG Color

Stage BG Color sets the background of the runtime stage to a solid colour.

FieldDescription
Color A CSS colour value, e.g. #1a1a2e, darkblue, or rgb(26, 26, 46).

Stage BG Image

Stage BG Image sets a background image on the runtime stage. The image is scaled to cover the stage area.

FieldDescription
Image The image file to display (e.g. forest.png). Images are loaded from the project assets.

Example

Stage commands in a block's command list:

☰ Stage BG Color #0d0d2b
☰ Say "The stars appear overhead."
☰ Stage BG Image starry_sky.png
☰ Say "A beautiful night sky fills your view."
Tip
Setting a BG Color before a BG Image provides a fallback colour that shows while the image loads.
