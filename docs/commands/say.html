Say

The Say command displays a line of text on the runtime stage. It is the most common command for presenting dialogue, narration, or instructions to the player.

Fields

FieldTypeDescription
Story Text String The text to display. Supports basic formatting.
Character String (optional) A character name shown above the text line (e.g. "Alice").

Behaviour

When a Say command executes, the stage displays the text and waits for the player to click or tap to continue. Once the player advances, execution moves to the next command in the block.

Example

A simple two-line conversation in the command list:

☰ Say Alice: "Hello! Welcome to the forest."
☰ Say Bob: "Thanks, Alice. It's good to be here."

The first Say command is selected (highlighted in green), showing its editor fields in the Inspector below the command list. Click any command row to select it and edit its properties.

Tip
Use the Menu command after a Say to let the player choose how the conversation branches.
