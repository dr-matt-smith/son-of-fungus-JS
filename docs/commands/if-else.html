If / Else-If / Else / End

The conditional commands let you branch execution within a single block based on variable values. They work together as a group: If, optional Else-If, optional Else, and End.

If

The If command evaluates a condition. If the condition is true, the commands that follow (up to the next Else-If, Else, or End) are executed.

FieldDescription
Variable The variable to test.
Comparison Operator: ==, !=, <, >, <=, >=.
Value The value to compare against (literal or another variable).

Else-If

Else-If adds an additional condition check. It is evaluated only if all preceding If / Else-If conditions were false. You can chain as many Else-If commands as you need.

Else

The Else command has no condition. The commands following it run only when every preceding If and Else-If condition evaluated to false.

End

End marks the end of the conditional group. After End, execution continues with whatever command comes next in the block, regardless of which branch was taken.

Example

Here is how an If / Else / End group appears in the command list. Note how commands inside branches are indented:

☰ If hasKey == true
☰ Say "You unlock the door."
☰ Else
☰ Say "The door is locked."
☰ End

Only one of the two Say commands inside the conditional group runs. The indentation makes it clear which commands belong to which branch. After End, execution continues with the next command in the block.

Tip
Every If must have a matching End. The editor will warn you if an End is missing.
