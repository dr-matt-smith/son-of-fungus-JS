Wait / Send Message

These commands control the flow of execution by introducing pauses or triggering event-driven blocks.

Wait

Wait pauses execution for a specified duration before moving to the next command.

FieldDescription
Duration Time to wait in seconds (e.g. 1.5).

Wait is useful for pacing — adding a brief pause between scene transitions, after a sound effect, or before revealing the next line of dialogue.

Send Message

Send Message broadcasts a named message. Any block with a Message Received event trigger that matches the message name will begin executing.

FieldDescription
Message The message name to broadcast. Select from messages registered in the Events tab, or type a new name.

Example

Wait and Send Message commands in a block's command list:

☰ Say "Something stirs in the distance..."
☰ Wait 2 seconds
☰ Send Message cutscene_start

The block sends the cutscene_start message after a 2-second pause. Any block listening for that message (with a Message Received event trigger) will begin executing when it arrives.

Tip
Register your message names in the Events tab so they appear in dropdowns throughout the editor and reduce the risk of typos.
