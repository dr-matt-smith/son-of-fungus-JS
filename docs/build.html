Build Runtime

The Build feature packages your project into a standalone, self-contained experience that runs in any web browser — no editor required.

Note
The build output is a ZIP file containing a single index.html plus any referenced audio and image assets. No server-side technology is needed — the result is pure static HTML, CSS, and JavaScript.

How It Works

Click the Build button in the top toolbar. Son of Fungus generates a ZIP file and triggers a download in your browser. The ZIP contains:

  • index.html — A standalone HTML page with the runtime engine and your project data embedded.
  • audio/ — Any music or sound-effect files referenced by Play Music or Play Sound commands.
  • images/ — Any background images referenced by Stage BG Image commands.

Hosting the Build

Unzip the archive and open index.html in a browser to play the project locally. To share it online, upload the entire folder to any static hosting provider (GitHub Pages, Netlify, a simple web server, etc.).

Because the runtime is pure HTML, CSS, and JavaScript with no server-side requirements, it works anywhere a browser can load a local file or URL.

Asset Handling

The build process copies referenced audio and image files into the ZIP automatically. Make sure all assets are loaded into the editor before building. Unreferenced files are not included, keeping the output as small as possible.

Tip
Always debug your project before building to catch any logic errors. The built runtime does not include debugging tools.
