Load & Save

Son of Fungus projects are stored as plain JSON files. The editor provides several ways to save your work and load it back later.

Export JSON

Click the Export JSON button in the top toolbar to download your entire project as a .json file. The file contains all blocks, commands, variables, enums, events, and canvas layout positions.

Keep these exports as backups or share them with collaborators — the JSON format is human-readable and version-control friendly.

Load Project

There are three ways to load a project into the editor:

Load Project Dialog
The Load Project dialog presents three sections, each offering a different way to bring data into the editor:
  • Examples Dropdown — Choose from a set of built-in example projects that demonstrate different features. Great for learning the tool.
  • Open File — Use the file picker to select a previously exported .json file from your computer.
  • Paste JSON — Open the paste dialog and paste raw JSON directly into the text area, then confirm. Useful for quick sharing or when copying project data from a message.

Confirm Dialog

Loading a project replaces everything currently in the editor. To prevent accidental data loss, Son of Fungus shows a confirmation dialog before any load operation. Make sure you have exported your current work first if you need to keep it.

Warning
Loading a new project cannot be undone. Always export your current project before loading a different one.
